# Calculo de média
Como calcular média de um aluno utilizando duas notas
***

# Tecnologias utilizadas
Python 3.13
***
```def calcular_media(nota1, nota2):
    return (nota1 + nota2) / 2

print("=== Sistema de Notas do Aluno ===")
n1 = float(input("Digite a primeira nota: "))
n2 = float(input("Digite a segunda nota: "))
media = calcular_media(n1, n2)
print(f"A média final é {media:.2f}")

if media >= 7.0:
    print("APROVADO!")
else:
    print("REPROVADO!") 
```

# Como instalar e executar
Instale Python 3.13 em seu computador, baixe o repositório, abra ele em um editor de código e rode

# Exemplo de uso
Digite uma primeira nota com utilizando ponto "7.0" por exemplo e a segunda nota utilizando o mesmo raciocínio
